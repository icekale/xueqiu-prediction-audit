# 入选 / 排除批注

`draft` 按**股票 / 方向 / 价格 / 时间**四元组扫候选，**不是**入选。下面用雪球 metalslime（药神）的真实口径，说明哪些进 `calls.json`、哪些扔掉。换账号时按同一标准，不要按粉丝或组合净值。

碎片评论、问答、只有「还能买」这种半句：可以先 LLM 补齐四元组，写成候选；**不要**把 LLM 草稿直接 `score`。粉丝问句里的多空不是作者方向。

## 入选

### 1. 结构空，作者自己写了期限

> 2021-03-15 · 抱团将在五年内重回大烂臭

```json
{
  "date": "2021-03-15",
  "theme": "抱团重回大烂臭，五年内完成",
  "side": -1,
  "symbol": "SZ399997",
  "horizon_m": 60,
  "kind": "structure",
  "cat": "白酒/抱团",
  "note": "原文写五年。改成 24 个月会因 2022–23 反弹误判"
}
```

为什么入：有日期、有空、能映射白酒指数。horizon 必须用作者的「五年」。

### 2. 结构空，标的是代理

> 2022-09-25 · 一线城市住宅双见顶

```json
{
  "date": "2022-09-25",
  "theme": "一线城市住宅双见顶",
  "side": -1,
  "symbol": "SZ000002",
  "horizon_m": 24,
  "kind": "structure",
  "cat": "地产",
  "note": "一线房价 → 万科"
}
```

为什么入：房价本身没有连续日 K，代理关系写进 `note`。

### 3. 战术 + 数字价位，拆成方向和价位

> 见底时茅台 1350–1400

方向可以另计一条看多指数；价位必须单独写 `price_target`。茅台有没有打到区间，才是价位分。不要因为指数后来涨了就把价位改成「对」。

### 4. 大 V 自己的评论，也是首次清楚表述

> 主帖只是复盘，评论里写「维持看空茅台」

入选。`fetch --mode deep` 会把作者评论收进 `posts.json`（id 以 `c-` 开头），`draft` 会扫到。粉丝的多空只作「回复：…」上下文，不进 `calls.json`。

### 5. 战术空喊在大底上，也要留下

> 2022-10 · 白马不是底

入选。后来作者又看多股市，不能回改这条。照做为负写进报告即可。

## 排除

### 6. 当天情绪，没有持有期

> 今天心情一般，这周看着难受

扔掉。没有多空，没有窗口。`draft` 也不该扫到；如果扫到了，删。

### 7. 只有框架，没有方向

> 去金融化、IRR、供需还是那套

扔掉。框架可以写进客户「跟单口径」当背景，不能当样本。

### 8. 组合调仓，没有写成判断

> 大票为主加了阳光电源

默认扔掉。组合净值走 `cubes`。只有作者在帖子里把调仓写成「现在看多阳光」，才另计一条，并在 `note` 写「组合非实盘」。

### 9. 同一论点的重复

> 2022 年再次数落抱团，没有翻案、没有新价位

扔掉。2021-03-15 已经入选。重复会把命中率刷高。

### 10. 段子、引用、阴阳

别人的多空，自己只转发或调侃：扔掉。

## 操作顺序

```bash
python3 scripts/xueqiu_audit.py draft work/UID/posts.json --out work/UID/candidates.json
```

打开 `candidates.json`，对照本页改成 `calls.json`：核四元组，补 `symbol` / `horizon_m` / `kind` / `price_target`，删情绪和重复，写代理 `note`。`needs_llm` 的条目先补齐再决定去留。然后：

```bash
python3 scripts/xueqiu_audit.py score work/UID/calls.json
```

`score` 碰到 `"draft": true` 会拒绝。打完分后把结论和三条跟单口径写进 `calls.json` / `scorecard.json` 的 `conclusion`、`playbook`，不要直接把自动稿交给客户。

`draft` 只认作者本句；被 `// @` 引用的别人多空、`@137-137-137` 这种用户名、没有「目标 / 见底 / 过」的光秃数字，都不当候选。
