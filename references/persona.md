# 行为画像 / 人格侧写 / 表述对照

客户报告里可以写公开习惯，MBTI 对照写在行为画像同一节，**不能**写测谎仪、骗子、临床诊断、星座。侧写提示词在下面；代码默认 `auto_persona` + `auto_mbti` + `auto_consistency`，也可用 `scorecard.persona` / `scorecard.mbti` / `scorecard.consistency` 手写覆盖。

画像和对照**不进入**命中或照做加权。

## 门槛

看已入选、已打分的 `rows`，不要看粉丝数或发帖总量。

| 级别 | 条件 | 报告标题必须写 |
| --- | --- | --- |
| `draft` | 条数 <8，或跨年不足 2 个自然年，或 `coverage=thin` | 习惯草稿，**不是人格测写** |
| `portrait` | 够 8 条且跨满 2 年，但还不够侧写 | 行为画像，**不是人格测写** |
| `profile` | 条数 ≥20，**且**跨满 4 个自然年，且不是薄样本 | 可以写「公开人格侧写」 |

跨年 = `max(year) - min(year) + 1`。Syedc 这种 43 条但只有 2024–2026，是 `portrait`，不是侧写。药神 39 条、2019–2026，才够 `profile`。

语料很多但可证伪判断很少：按判断跨年，不按注册日或帖子跨年。

## 禁止写

- 大五人格、星座、临床诊断、反社会、病态、人格障碍
- 把 MBTI 写成正规量表、心理咨询结论或「他就是这种人」
- 测谎、撒谎、骗子、心术、阴暗、PUA
- 「他其实是这样的人」却给不出日期或计数
- 把口头禅次数当成性格量表

只写**公开行为**：同一标的翻案几次、结构/战术谁更稳、有没有十倍百倍口号、窗口对了还拿不拿得住、事后有没有认卖飞。

## 行为画像提示词

用于 `portrait` / `draft`，或 `auto_persona` 的手写覆盖。

```
你在做公开预测审计的行为画像，不是心理咨询。

只用已入选、已打分的判断（日期、多空、标的、结构/战术、窗口对错、照做、回撤）。有语料时只数口头禅，不当量表。

先判级别：不够 8 条或跨年不足 2 年或薄样本 → 草稿，标题必须有「不是人格测写」。够 8 条但跨年不足 4 年 → 画像，标题仍必须有「不是人格测写」。不要升级成人格侧写。

写一句话主张 + 最多 5 条习惯。每条必须带日期或计数。行为画像里不要写 MBTI 四字母。禁止大五人格、星座、临床诊断。不要给买卖指令。
```

## 人格侧写提示词

只在 `profile` 门槛过了之后用。仍然是公开文本侧写，不是量表。

```
样本已经跨满 4 个自然年，且不少于 20 条可证伪方向。可以做公开人格侧写，仍然不是心理诊断。

只从公开帖和计分表归纳稳定偏好：
- 时间偏好：结构框架 vs 战术点位，谁更能拿住
- 风险偏好：回撤多大还继续说、什么时候清仓
- 语言偏好：数量级口号、口头禅、对线还是认错
- 更新规则：翻案有没有说明、错了会不会写卖飞
- 自我叙事：后来有没有把复盘说成「我早就知道」

每条主张必须能指回日期或计数。人格侧写正文不要用四字母类型（那是下一节）。禁止大五人格、星座。不要推测私下动机、家庭、病理。不要写成「他是个××型的人」却没有证据。标题可以写「公开人格侧写」，结尾必须写「不是心理诊断」。
```

## MBTI 对照提示词

写进**行为画像**同一节，不要另开章节。只对照公开发帖和计分表，**必须**写「不是量表」。四个字母每个都要有证据（回复/原创比、结构/战术、业绩词/心态词、翻案次数）。

```
你在做公开文本的 MBTI 风格对照，不是替作者做正规 MBTI 测验，也不是心理诊断。

只看已打分判断，外加语料里的回复比和口头禅。四个维度都要选边，但每个字母必须能指回计数或日期：
- E/I：回复、对线、口头禅 vs 原创长文
- S/N：战术点位 vs 产业/周期/数量级口号
- T/F：业绩、仓位、价位 vs 心态、卖飞、纠错
- J/P：清仓/拿到结束/一定 vs 翻案、逢低、波段

标题写成「公开文本对照偏 XXXX。不是量表。」禁止星座、临床诊断、大五人格。不要根据类型给买卖指令。
```

手写覆盖字段：`scorecard.mbti = {draft, type, headline, axes[{axis, letter, lean, evidence}], note}`。

## 表述对照（不要叫测谎）

公开文本**不能测谎**。没有基线问题、没有生理信号，也看不到没发出来的仓位。能做的是：后来怎么说，对上当时怎么写。

报告章节名必须是 **表述对照**。禁止出现：测谎、测谎仪、撒谎、骗子。

对照三种公开现象：

1. **翻案**：同一标的后一条和前一条方向相反，后一条又没有「卖飞 / 认错 / 反思 / 纠错」→ **对不上**
2. **事后改口**：窗口已经判错，后来同一标的或同一主题写了卖飞/认错 → **对得上**
3. **事后叙事**：行情走出来之后说「当初没人信 / 早就说过 / 我说的没错」→ **需对照**首次入选日，不要把复盘当成当时判断

```
你在做公开表述对照，不是测谎。

输入是已打分的判断，外加后来的帖。输出一张表：类型、后来怎么说、当时怎么写、对照（对不上 / 对得上 / 需对照）。

只标记能指回日期的句子。不要判断作者内心是否故意骗人，不要写「他在撒谎」。标题禁止出现「测谎」。注释必须写「对照的是公开表述和计分表，不是测谎」。
```

手写覆盖字段：`scorecard.consistency = {headline, items[{kind, claim, record, verdict}], note}`。
