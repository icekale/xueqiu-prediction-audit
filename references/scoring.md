# 计分细则

## 入选

留下能被证伪的句子：

- 有公历日期（帖子或长文发布时间）。
- 有方向：看多 / 看空 / 拒绝抄底 / 现在可以买 / 死空。
- 能映射到流动标的或指数（个股、行业指数、沪深300、恒指）。「一线房价」可代理为万科等一线开发商，并在表里写明代理关系。

同一论点只取**第一次说清楚**的日期。后来重复、加条件、改期限，不算新样本。下列情况另计一条：

- 明确翻案（空 → 多，或反过来）。
- 新的数字价位（「飞天到 1200」）。
- 新的标的篮子（从空白酒改成空一切内需，若代理标的变了）。

## 排除

- 段子、阴阳、引用别人且无自己方向。
- 「今天心情」「这周看着难受」且无持有期。
- 只有研究框架（供需、IRR、去金融化）没有多空。
- 组合调仓记录：可以当**注释**，不能当预测样本，除非作者在帖子里把它写成方向判断。

## 结构 vs 战术

| | 结构 | 战术 |
| --- | --- | --- |
| 典型 | 抱团五年回大烂臭；一线城市双见顶；名创式 IP 出海 | 现在可以买；拒绝抄底；见底；梭回 |
| 窗口 | 作者期限，缺省 12–24 个月 | 作者期限，缺省 3–6 个月 |
| 客户用法 | 可以参考框架 | 默认作废 |

一条里既有框架又有买卖点：框架进结构，买卖点进战术，不要并成一条。

## 窗口

```
start = 帖子日期的下一根可交易前复权收盘（若当日有收盘，用当日）
end   = min(start + horizon, 样本截止日, 最后一根 K 线)
ret   = end.close / start.close - 1
```

再算：

- `todate`：从 start 拿到样本截止日。
- `mfe` / `mae`：窗口内最高/最低相对开仓价。
- `giveback`：从最高点到至今。

近端样本（horizon 未走完）在表里标「窗口不足」，不要假装已经证毕。

## 方向阈值

多头：`>+5%` 对；`<-10%` 错；`−10%～−5%` 偏错；其余平。  
空头：`<-8%` 对；`>+10%` 错；`+5%～+10%` 偏错；其余平。

阈值不对称：空头少赚一点就能算方向对，因为我们要的是「有没有踩对大方向」，不是交易员的盈亏比。

## 价位

数字目标单独判。例如「茅台 1350–1400 则指数见底」：

- 指数方向可以另计。
- 茅台是否在约定天数内打到区间，才是价位分。
- 批价、批发价要写数据源和观察日；没有可靠批价就写「无法评分」，不要用股价代替。

## 照做

```
copy = side * ret_window
```

等权平均。同时给中位数。均值会被单笔十倍票拉歪，客户稿先报中位。

不要自动减沪深300。若要讲超额，另开一列 `excess = ret_window - csi300_window`，不要替换照做。

## 对照

至少做三条朴素策略，和「等权照做全部样本」比：

1. 把最稳的那条结构空一直拿到现在。
2. 把最稳的那条结构多一直拿到现在（若有）。
3. 同期一直持有沪深300。

若单独拿住一两条结构，已经好于等权 全部样本，把这句话写进结论。

## 分年 / 分主题

- 命中 = 窗口方向为「对」的条数 / 当年（或该主题）条数。偏错、平、错都不算命中。
- 照做报该桶的等权均值；客户稿可再补中位。
- 年份样本 <3 不要单独吹「100%」。

## 组合

公开组合只做附录：

- 运行起止、是否停更、作者有没有写「非实盘」。
- 净值**不**进入方向命中和照做加权。
