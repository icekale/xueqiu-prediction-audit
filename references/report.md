# 客户报告

给客户的是浅色单栏稿，不是内部深色 canvas，也不是米色宋体研报。

## 版式

- 宽度 720px 单栏，导出 PDF 用 A4。
- 字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Hiragino Sans GB", sans-serif`
- 字号：H1 24/30/590，H2 18/24，H3 16/22，正文 14/20，小字 12/16
- 间距：段间 20，组内 8，标题下 6
- 圆角：框 6，卡片 8
- 禁止：渐变、emoji、box-shadow、红绿灯标签、宋体、暖色纸纹、内部版本号

浅色 token：

```css
--bg: #ffffff;
--fg: #141414;
--fg-2: rgba(20, 20, 20, 0.74);
--fg-3: rgba(20, 20, 20, 0.50);
--stroke: rgba(20, 20, 20, 0.12);
--fill: rgba(20, 20, 20, 0.06);
--link: #2e79b5;
--danger: #c04848; /* 仅图表，不给对错打红绿章 */
```

打印：

```css
@media print {
  html, body { background: #fff; color: #141414; }
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}
@page { size: A4; margin: 14mm 12mm; }
```

不要给整张大表加 `break-inside: avoid`（会裁切）。行可以避分。

## 结构

1. **标题 + 元信息**：账号、UID、样本数、起止、价格截止、复权口径。
2. **结论**（Callout）：三到五句。先结构/战术，再价位，再「哪两条一直拿到现在已经够用」。
3. **四格**：结构方向对 · 战术方向对 · 战术照做中位 · 数字价位打中。
4. **跟单口径**：三条。1 框架可参考、组合和情绪帖不能跟。2 最稳的空/多是什么、要接受什么回撤。3 数字价位和「现在可以买/卖」作废，举近端反例。
5. **照做与对照**：全部等权均值/中位 + 只做结构 + 只做战术 + 朴素对照表。
6. **分年** + 命中率柱（中性灰紫，不要彩虹）。
7. **分主题**。
8. **价位与立场翻转**。
9. **窗口对、拿到现在不是一回事**（名创/大金这类回吐用三张卡片）。
10. **明细表**：日期、向、类、判断、窗口、照做、至今。
11. **方法**：入选/排除/阈值/等权/非实盘/非投资建议。
12. **页脚**：主页链接 · 语料规模（原创条数、长文数）。

## 导出

Chrome headless。命令容易僵死，stdout 重定向，外层 timeout 20–25s。PDF 加 `--no-pdf-header-footer`。PNG 用 `--force-device-scale-factor=2`，再按白底裁掉底边空白。

暗色稿只留在编辑器侧栏预览。客户 PDF/PNG 一律浅色。

## 文案

- 用「对 / 平 / 偏错 / 错」，不要「准确」「神准」。
- 中位和均值同时出现时，先说中位。
- 组合暴赚写进**单独的组合报告**并写停更日期，不当预测标题数字。

## 组合报告

`cubes` 出另一张浅色单栏稿，不要和预测四格混排。

1. 标题：账号 + 公开组合量化。
2. 口径框：模拟盘、非实盘声明、不进命中、不是投资建议。
3. 每个可计算组合一块：主张句（超额确实很强 / 虽然短但突出 / 对基准）+ 起止与天数 + 表（标的 / 累计 / 年化，短于一年不写年化）+ 超额百分点与财富倍数。
4. 未纳入的组合用一行说明原因（净值点太少、无法解析）。

数字用两位小数（+319.96%），对齐全表。禁止把雪球卡片累计直接抄进表，用首末净值。
- 不要出现「v1」「v2」「我们改了口径」。
